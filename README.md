# 🚀 Mission H

Mission H is a mobile application project developed with Unity. It offers an interactive environment with a system of dialogues, interactions with various NPCs (teachers, students), and optimized controls for smartphones. The project comes with a dedicated web-based administrative interface (`app_admin`) for application data management.

## ✨ Key Features

*  **Mobile Controls:** Integration of a native virtual joystick for smooth and intuitive navigation.
*  **Dynamic Dialogue System:** Scripted interactions with characters, including a skip logic.
*  **Living Environment:** Presence of multiple NPCs (students and a diverse panel of teachers).
*  **Administrative Dashboard :** Web space (`app_admin`) for managing the technical aspects and content of the application.

## 🛠️ Technical Stack

*  **Game Engine / App :** Unity (C#)
*  **Back-office / Web :** Node.js
*  **Deployment:** Docker (Containerized architecture via Dockerfile)

## ⚙️ Depot Architecture

*  `/Assets` : Unity C# scripts, scenes, sprites, templates, and prefabs.
*  `   `/Packages` : Dependencies and packages for the Unity project.
*  `/ProjectSettings` : Set up inputs, graphics, and the publisher.
*  `/app_admin` : Administrative dashboard source code (API/web).

At its core, it is an educational game designed to teach players about different types of disabilities in a fun and engaging way.


## EN FRANCAIS 🇫🇷

# 🚀 Mission H

Mission H est un projet d'application mobile développé avec Unity. Il propose un environnement interactif avec un système de dialogues, des interactions avec divers PNJ (professeurs, élèves), et des contrôles optimisés pour les smartphones. Le projet s'accompagne d'une interface d'administration web dédiée (`app_admin`) pour la gestion des données de l'application.

## ✨ Fonctionnalités Principales

*   **Contrôles Mobiles :** Intégration d'un joystick virtuel natif pour une navigation fluide et intuitive.
*   **Système de Dialogue Dynamique :** Interactions scriptées avec les personnages, incluant une logique de "skip".
*   **Environnement Vivant :** Présence de multiples PNJ (élèves et un panel diversifié de professeurs).
*   **Dashboard d'Administration :** Espace web (`app_admin`) permettant de gérer les aspects techniques et le contenu de l'application.

## 🛠️ Stack Technique

*   **Moteur de Jeu / App :** Unity (C#)
*   **Back-office / Web :** Node.js
*   **Déploiement :** Docker (Architecture conteneurisée via Dockerfile)

## ⚙️ Architecture du Dépôt

*   `/Assets` : Scripts C#, scènes, sprites, modèles et prefabs Unity.
*   `/Packages` : Dépendances et packages du projet Unity.
*   `/ProjectSettings` : Configuration des inputs, des graphismes et de l'éditeur.
*   `/app_admin` : Code source du tableau de bord d'administration (API/Web).

À l'origine, il s'agit d'un jeu éducatif conçu pour sensibiliser et faire apprendre, de manière ludique, les différents types de handicap.
