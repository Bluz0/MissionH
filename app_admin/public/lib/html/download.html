Comment installer l'application ?

01

Téléchargement

Récupérez le fichier via le bouton ci-dessous ou en scannant le QR code avec votre mobile.

02

Autorisation

Si un message "Fichier potentiellement dangereux" apparaît, cliquez sur "Télécharger quand même". C'est une alerte standard d'Android.

03

Installation

Ouvrez le fichier .apk. Si le système bloque, allez dans Paramètres et cochez "Autoriser cette source".

Information importante

L'application n'est disponible que sur Android. Les utilisateurs d'iPhone ne peuvent pas installer de fichiers APK.
